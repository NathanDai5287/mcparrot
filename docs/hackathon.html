LA Hacks 2026

This page covers the hackathon only: how judges score projects, which prizes we aim for, and what we submit. The product guide explains what MCParrot does.

Devpost deadline Oct 18, 2026 · in-person judging required

Event deadline and attendance

We are entering AI Hackathon 2026 by LA Hacks at UCLA. Devpost, the website where teams submit their projects, closes on Oct 18, 2026 at 12:00pm PDT. You must attend the judging phase in person to receive a score and win prizes. Use the LA Hacks event website to apply, RSVP, and check the schedule.

How judges score projects

LA Hacks uses the same four criteria for every project.

Official judging criteria
CriterionWhat judges look for
Technical depthReal engineering effort, thoughtful design, and work that goes beyond a thin template or plug-in demo.
Product thinking and impactA clear problem and user, thoughtful product choices, and believable real-world benefit.
Execution and polishWorking features, a smooth live demo, and a cohesive experience.
Originality and insightA fresh angle, clever build, or insight that makes the project memorable.

Our demo should show one complete path that works from start to finish. It should also name what is still planned, and it should tell the user story before the technical details.

Choosing a Devpost track

Each project enters one main track on Devpost. Applied Intelligence is our primary track, because it rewards practical AI that improves everyday work: you teach a task once, then use it from your assistant. Agentverse, the track of the company Fetch.ai, also fits if we show your request turning into real action through saved tools or agent discovery. We must name the chosen track in the Devpost description.

Sponsor prizes we want

We enter a sponsor category only when the live demo honestly meets the rules of that sponsor. Browser Use is a service that runs web browsers for us, and Sentry is a service that reports errors and slow steps in an app.

What we must submit

  • Project description — what it does, the problem, our track, and any sponsor categories.
  • Public repository — the project source code, with documentation.
  • Demo video (2–3 minutes) — a walkthrough of the features and how they work.
  • Complete Devpost page — a summary, the technologies we used, and links such as designs and reference documents.
Source of truth

Grand prizes and some prize amounts may change. Use Devpost and the LA Hacks event website for the final rules and prize text.
