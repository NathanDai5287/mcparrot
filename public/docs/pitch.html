Recording without leaking secrets.

Explorer uses Chrome’s debugger permission to see the requests a page makes, with no host permissions. Claude only ever sees redacted samples.

Kept

  • Data requests, with samples cut to 400 characters per value and 5 items per list
  • Request bodies up to 30,000 characters, so GraphQL queries stay whole
  • Request headers that are not secret, and the visible text of whole pages
  • The name of a sign-in header and its local storage key, never the value

Dropped

  • Cookies and the authorization header
  • Values under secret names such as token and password
  • JWTs and Bearer values, wherever they appear
  • Real sign-in pages, such as login, oauth, and 2fa

Explorer 0.8.0 passed these rules in a local test browser. A live recording with 0.8.0 is a gap on the status page.

What a tool does when ChatGPT calls it.

  • Stays on the website. A tool may call any host under the site’s registrable domain, so us.edstem.org works for edstem.org, and nothing else.
  • Reads sign-in tokens at run time. Ed sends X-Token from local storage, so the tool reads it inside the page by name. It never reaches a tool, a log, or Claude.
  • Gets a fresh CSRF code. Before a POST, it reads the code from the page’s meta tag, hidden input, or CSRF cookie.
  • Chains steps. A placeholder such as {step1.cartId} fills a later request from an earlier answer.
  • Refuses to pay. One guard blocks any request that looks like checkout or payment, in tools and in tools ChatGPT saves.
  • Reports honestly. Signed out, bot checks, and refused CSRF codes each get their own message.

Running tools from ChatGPT is shipped. Token headers, CSRF codes, and step placeholders pass local tests, and their first live runs on real websites are gaps on the status page.

Pictures and speed.

ChatGPT cannot see pictures from a connector

  • ChatGPT drops MCP image results; OpenAI support confirmed it in April 2026.
  • view_image opens the picture in the signed-in browser, shrinks it to 1,600 pixels, and has Claude Opus 5.5 copy its words and numbers.
  • That is how ChatGPT read the Ed exam statistics in the Gradescope and Ed example.

A warm browser between calls

  • The app’s browser stays open for up to 7 minutes and serves each call in a new tab.
  • A simple page: 3.2–3.6 s cold, 2.5 s warm. A larger page: 4.8–5.6 s cold, about 4 s warm.
  • Sign-in, codes, and deleting the app close it first, so an old sign-in never overwrites a new one.

Timings come from a test script with a throwaway profile. The warm browser and reading pictures from the app page are gaps on the status page.

Signing in and paying, safely.

Signing back in shipped

  • The saved login is encrypted with AES-256-GCM and reaches the agent only as secret bindings.
  • One sign-in at a time per app, never the same rejected password twice, and a ten-minute pause after a failure.
  • A text-message code goes from you, through ChatGPT, to the waiting browser.
  • “Continue with Google” reuses the profile’s Google session, with no Google password gap

Ordering gap

  • An agent fills the cart and stops; ChatGPT shows items, fees, and the total.
  • Only after you approve does an agent pay with a one-time Pay with Link card.
  • The server refuses above your limit, if the total changed by a cent, or whenever Link is not in test mode.
  • Browser Use said Link test mode is not realistically available, so live payment stays blocked.
